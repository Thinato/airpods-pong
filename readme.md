# AirPods Pong

This is a simple Pong that is played with your AirPods.

Uses `bluez` to listen to AirPods volume changes.

## Demo

https://github.com/user-attachments/assets/9f9ed8e0-dd5a-4014-92b6-22de1c285f41

I'm holding the airpods in a weird way, because it only registers volume change when it thinks it is inside a ear, so i have cover the proximity detectors.
